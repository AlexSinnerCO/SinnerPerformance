# Sinner Performance

Website der Tuningwerkstatt Sinner Performance in Bersenbrück (BMW Tuning).

Dies ist die **Vorschau-Version**: reines HTML, CSS und JavaScript, ohne Server-Funktionen.
Sie lässt sich direkt im Browser öffnen (`index.html`) oder über GitHub Pages anzeigen.

## Seiten

- `index.html` Startseite
- `leistungen.html` Leistungen
- `projekte.html` Projekte
- `ueber-uns.html` Über uns
- `anfahrt.html` Anfahrt mit Karte
- `anfrage.html` Anfrageformular (verschickt in dieser Version nichts)
- `impressum.html`, `datenschutz.html`, `404.html`

## Hinweise

- Das Anfrageformular funktioniert erst in der Live-Version mit PHP (`senden.php`) auf einem Webspace.
- Kartendaten der Anfahrtsseite: © OpenStreetMap-Mitwirkende.
- Schriften (Chakra Petch, Barlow) liegen lokal unter `assets/fonts/` (SIL Open Font License).
